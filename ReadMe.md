## Nepal Landslide Risk

### Overview

This project is built using [Google Earth Engine](https://earthengine.google.com/) and compares different ML models (pulled from literature attempting to show landslide susceptibility and varying scales) against reported landslides instances and their associated damage. This was done as a team of five and is not solely my own work.
